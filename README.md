# 在线商城系统测试实践

## 测试范围
- 功能测试：覆盖注册/登录/商品/购物车/订单/后台管理模块
- 接口测试：Apifox 完成核心接口文档化与自动化串联
- 性能测试：JMeter 阶梯加压 + 混合场景压测
- 自动化测试：pytest + requests 接口自动化框架

## 被测系统
- ShopXO 演示站：https://demo.shopxo.net/
- mall 开源商城：https://gitee.com/macrozheng/mall

## 目录结构
- docs/      测试文档（用例、缺陷报告、流程图）
- scripts/   自动化测试脚本
- jmeter/    性能压测脚本
